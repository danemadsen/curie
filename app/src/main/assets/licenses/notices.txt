Curie open source notices
=========================

Curie runs the LFM3-Omni-2B model with ONNX Runtime and is built on the open source
software below. Each entry names the file in this folder that holds its license.


The model
---------

LFM3-Omni-2B (ONNX export), by Liquid AI, Inc.
    https://huggingface.co/LiquidAI/LFM3-Omni-2B-ONNX
    Revision 7d6bd3fd59a0622e5ce7fefc141145a8bba1435a. Curie downloads the model at
    runtime; the app package does not contain it.
    License: LFM Open License v1.0 (lfm-open-license-1.0.txt)

The Curie voice (assets/lora in the app package)
    decoder_q4.lora.onnx and depth_decoder.lora.onnx are modified copies of the
    decoder_q4.onnx and depth_decoder.onnx graphs of LFM3-Omni-2B-ONNX: Curie added
    LoRA inputs to them. decoder_q4.onnx_adapter and depth_decoder.onnx_adapter hold a
    LoRA adapter trained on LiquidAI/LFM3-Audio-2B, which Curie applies to the
    corresponding weights of LFM3-Omni-2B.
    License: LFM Open License v1.0 (lfm-open-license-1.0.txt)
